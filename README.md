# Oregon Lottery Partnership Review

Interactive presentation by Plan A Technologies. The content is encrypted and opens with the shared password.

## Publish on GitHub Pages
1. Upload `index.html` to the root of the repository.
2. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
3. After a minute or two the deck is live at `https://<your-user>.github.io/<repo>/`.

## Presenting
- Next / previous: arrow keys, space, clicking the slide, or swiping on a phone
- On the priorities slide, the arrow keys step through each priority before moving on
- **O** shows a grid of all slides, **F** goes fullscreen, **?** lists the shortcuts
- Add `#6` to the address to open on a specific slide
